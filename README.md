gpaste-fzf-out
================

This is a badly written little helper I threw together to replace the GPaste GNOME-extension, because those extensions seem to break with every desktop update. It currently shells out to `fzf` for the picker UI and assumes you are running inside `kitty`. Inside the picker you can press `ctrl-d` or the `Delete` key to remove the highlighted history item straight from GPaste. Use at your own risk.
